# Data

The dataset is not included in this repository. Download it from Kaggle:

**[Medical Students Dataset](https://www.kaggle.com/datasets/slmsshk/medical-students-dataset)**

1. Download the CSV with all columns, including Cholesterol, Diabetes and Smoking.
2. Save it here as `data/medical_students_dataset.csv`.

Running the notebook or `src/preprocessing.py` writes the cleaned output to `data/medical_students_clean.csv`.

| Column | Description |
|---|---|
| Student ID | Unique identifier |
| Age | Age in years |
| Gender | Male / Female |
| Height | Height in cm |
| Weight | Weight in kg |
| Blood Type | A, B, AB, O |
| BMI | Body Mass Index (as supplied) |
| Temperature | Body temperature (°F) |
| Heart Rate | Beats per minute |
| Blood Pressure | Blood pressure reading |
| Cholesterol | Cholesterol level (mg/dL) |
| Diabetes | Yes / No |
| Smoking | Yes / No |
